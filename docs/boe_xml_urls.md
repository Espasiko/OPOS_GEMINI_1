### Cómo obtener los XML internos de cada código
1) Abrir el código (URL anterior) y en la pestaña «Legislación» extraer cada enlace al BOE (cada uno tiene `id=BOE-A-...`).
2) Convertir a XML con `https://www.boe.es/diario_boe/xml.php?id=<ID>`.
3) Ingerir en el pipeline RAG.

*(Si quieres, en el siguiente paso puedo scrapear los `id=BOE-A-...` del "Código Laboral y de la Seguridad Social" y añadir sus XML aquí mismo.)*
