# 📂 Dataset Generator & Inventory

**Last Organized: 2025-12-22 15:55**

## 🏆 Golden Dataset (Ready for Fine-Tuning)
The final, consolidated, and verified data is located in `golden_dataset/`.

### 1. Standard QA (`golden_dataset/standard/`)
Standard format: `{"pregunta": "...", "opciones": [], "respuesta_correcta": "...", "explicacion": "..."}`
- **`groq_500_qa_verified.jsonl`** (500 items): High-quality test questions generated by Llama 3.3.
- **`mistral_legacy_qa_consolidated.jsonl`** (671 items): Validated questions from Mistral batches.
- **`deepseek_extreme_cases.jsonl`** (150 items): "Expert" difficulty case studies.
- **`deepseek_premium_qa.jsonl`** (60 items): Complex Chain-of-Thought case studies.

### 2. Enriched Data (In Progress)
- **`golden_dataset/enriched/official_exams_enriched_mistral.jsonl`**: Official Exam questions enriched with legal references using Mistral API. (Goal: 5000+ items).
- **`golden_dataset/special/new_flashcards_batch.jsonl`**: High-quality flashcards for Anki/Study.

### 3. Special Formats (`golden_dataset/special/`)
- **`legacy_dialogues.jsonl`**: Conversational Q&A pairs (User/Assistant).
- **`legacy_flashcards.jsonl`**: Concept headers and summaries.
- **`legacy_rag_context.jsonl`**: Questions with explicit normative context text.

## 🗄️ Archive & Structure
To keep the workspace clean, files have been organized:
- **`archive/`**: Contains raw batch results and old outputs.
- **`dataset_generator/`**: Contains active scripts.
  - `enrich_official_exams.py`: Script driving the enrichment.
  - `generate_flashcards_batch.py`: Script for flashcards.
  - `groq_batch_service.py`: Service for managing Groq batches.

## 🚀 How to Add More Data
1. Run a generation script (e.g., `generate_premium_deepseek_batch_fixed.py`).
2. Run `python3 consolidate_legacy_and_batch.py` to merge new results into `golden_dataset`.
