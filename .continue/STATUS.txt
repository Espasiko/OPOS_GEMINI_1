🔧 PRÓXIMOS PASOS:
════════════════════════════════════════════════════════════════

1️⃣  OBTENER API KEY
    Ir a: https://console.anthropic.com/account/keys
    Copiar clave que comienza con "sk-ant-"

2️⃣  CONFIGURAR VARIABLE DE ENTORNO
    export ANTHROPIC_API_KEY='sk-ant-xxxxxxxxxxxxx'

3️⃣  COPIAR CONFIGURACIÓN A VS CODE
    cp config.yaml ~/.continue/config.yaml

4️⃣  VERIFICAR INSTALACIÓN (OPCIONAL)
    bash diagnose.sh

5️⃣  REINICIAR VS CODE
    Cierra y reabre VS Code
    Presiona Ctrl+L para abrir Continue Chat
