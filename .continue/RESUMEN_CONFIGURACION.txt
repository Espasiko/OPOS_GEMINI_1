📝 PASOS DE INSTALACIÓN RÁPIDA
═══════════════════════════════════════════════════════════════

PASO 1: Obtener API Key
  → https://console.anthropic.com/account/keys
  → Copiar clave que comienza con "sk-ant-"

PASO 2: Configurar variable de entorno
  → export ANTHROPIC_API_KEY='sk-ant-xxxxx'
  → O agregar a ~/.bashrc / ~/.zshrc para permanencia

PASO 3: Copiar configuración
  → cp /home/spas/OPOS_GEMINI_1/.continue/config.yaml ~/.continue/

PASO 4: Verificar instalación
  → bash /home/spas/OPOS_GEMINI_1/.continue/diagnose.sh

PASO 5: Reiniciar VS Code
  → Cierra y reabre VS Code
  → Presiona Ctrl+L para abrir Continue Chat

💡 TIPS & TRICKS
═══════════════════════════════════════════════════════════════

• Usa Sonnet por defecto → mejor relación precio/rendimiento
• Usa Opus para problemas complejos → mejor precisión
• Usa Haiku para autocomplete → más rápido
• Prompt Caching reduce costos → activa en config.yaml
• /refactor, /test, /document → comandos personalizados
• Las reglas se aplican automáticamente a todo
• Ctrl+L abre chat, Ctrl+I edita selección

❓ SOLUCIÓN DE PROBLEMAS COMÚN
═══════════════════════════════════════════════════════════════

ERROR: "API Key not found"
→ Ejecuta: export ANTHROPIC_API_KEY='tu-api-key'

ERROR: "Model not available"
→ Recarga VS Code: Ctrl+R (o Cmd+R)

ERROR: "config.yaml not found"
→ Copia: cp config.yaml ~/.continue/

ERROR: "MCP server failed"
→ Verifica: Python está instalado y config.yaml correcto
